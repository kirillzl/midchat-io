Midchat — Privacy Policy (suite)

Last updated: 2026-11-09

This page covers the Midchat website (midchat.io) and how we handle data when you contact us. Each ChatGPT plugin also has its own privacy page describing that product:

  • Mizar privacy
  • Lyra privacy
  • Kaus privacy
  • Alcor privacy
  • Vela privacy

Who we are

Published by Midchat. Privacy: privacy@midchat.io · Support: support@midchat.io.

Website

This is a static informational site. Our hosting provider (GitHub Pages) may process technical data (IP address, browser, time) to deliver and secure the site — see https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement. We set no cookies. A cookieless page-view counter records only the site name, hostname, and event type.

Mizar hosted server

Mizar (from version 1.1.0) uses Midchat’s hosted MCP server at https://mcp.midchat.io/mcp (Vercel, Frankfurt, EU). It receives only the invoice details needed to compute and render an invoice and stores none of them — see the Mizar privacy policy.

Lyra hosted server

Lyra (from version 1.1.0) uses Midchat’s hosted MCP server at https://lyra.mcp.midchat.io/mcp (Vercel, Frankfurt, EU). It receives only the report items needed to draft a weekly status and stores none of them — see the Lyra privacy policy.

Kaus hosted server

Kaus (from version 1.1.0) uses Midchat’s hosted MCP server at https://kaus.mcp.midchat.io/mcp (Vercel, Frankfurt, EU). It receives only the meeting content needed to build an action list and stores none of it — see the Kaus privacy policy.

Alcor hosted server

Alcor (from version 1.1.0) uses Midchat’s hosted MCP server at https://alcor.mcp.midchat.io/mcp (Vercel, Frankfurt, EU). It receives only the receipt details needed to build an expense sheet and stores none of them — see the Alcor privacy policy.

Vela hosted server

Vela (from version 1.1.0) uses Midchat’s hosted MCP server at https://vela.mcp.midchat.io/mcp (Vercel, Frankfurt, EU). It receives only the document text and table data needed to build the export and stores none of it — see the Vela privacy policy.

The plugin servers keep anonymous usage counts: for each tool call we log only the plugin name, tool name, time, whether it succeeded and how long it took, and never your content, files or identifiers.

Your rights

GDPR rights for data we hold: contact privacy@midchat.io. You may also complain to a data protection supervisory authority in the EU member state where you live or work.
