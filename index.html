ChatGPT plugins

Work that finishes in the chat.

Midchat is a suite of ChatGPT plugins for freelancers and operators — invoices, Friday status, meeting actions, expenses, and PDF tables — built to be recommended mid-conversation, not buried in a marketplace.

The five plugins

Mizar

Invoices from notes · skills-only

Paste notes, hours, or a timesheet into ChatGPT. Mizar turns them into a clean, tax-ready invoice — exact totals, VAT per rate, English or German.

Learn more →

Lyra

Weekly wrap-up · skills-only

Paste bullets, notes, or a metrics CSV. Get a short client email plus a one-pager with wins, progress, blockers, risks, and next steps. Tone: direct, no fluff.

Learn more →

Kaus

Recurring action lists · skills-only

Paste meeting notes or a transcript. Get a table of owner / action / due date / source quote, plus draft Slack or email follow-ups you send yourself.

Learn more →

Alcor

Receipts → expenses · skills-only (verify first)

Attach receipt photos or PDFs. Get one row per receipt with date, merchant, gross, VAT, net, currency, and category — plus a review list before export.

Learn more →

Vela

PDF tables → Sheets · hold for MCP

Attach a PDF. Get every table in source order with cleaned headers, ISO dates, plain decimals, a preview, and a totals check. Multi-page tables are stitched.

Learn more →
