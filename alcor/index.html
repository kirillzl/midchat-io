How it works

  1. Attach receipt photos or PDFs, or paste receipt text.
  2. Review the table and the “Needs your check” list.
  3. Copy the CSV into your spreadsheet, or send it to your accountant.

Say it like this

  • turn these receipts into an expense sheet
  • turn these receipts into a spreadsheet
  • expense report from these photos
  • prepare these expenses for my accountant as CSV

What you get

12 receipts → review table → totals by category → expenses.csv for your bookkeeper.

Good to know

  • Receipt images are read by ChatGPT, not a dedicated OCR engine. Check the values against the receipts before you file them.
  • Unreadable amounts stay empty and are flagged, not estimated. Amounts are converted only with an exchange rate you provide.
  • You get copy-paste CSV (standard or German). A downloadable file only where ChatGPT can run code.
  • No memory across chats. Receipt data is not stored.
  • Uses Midchat’s hosted tools at alcor.mcp.midchat.io, with no sign-in. It does not sync to accounting software, submit claims, produce a DATEV import, or advise on deductibility.
