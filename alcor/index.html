Alcor

Receipts → expenses.

Alcor turns receipts into an expense sheet: attach receipt photos or PDFs (or paste receipt text) and get one row per receipt with date, merchant, gross, VAT, net, currency, and category — plus a review list, totals by category and a CSV.

How it works

  2. Review the table and the “Needs your check” list.
  3. Copy the CSV for your spreadsheet or accountant.

Good to know

  • Receipt images are read by ChatGPT, not a dedicated OCR engine — please check the values against your receipts before filing.
  • Designed to leave unreadable amounts empty and flag them instead of estimating; amounts are converted only with an exchange rate you give.
  • Returns copy-paste CSV (standard or German format); a downloadable file only where ChatGPT can run code.
  • No memory across chats; receipt data is not stored.
  • Uses Midchat’s hosted tools at alcor.mcp.midchat.io (no sign-in). Does not sync to accounting software, submit claims, produce the DATEV import format, or advise on deductibility.
