Alcor — Support

Contact: support@midchat.io · Typical response: within 3 business days · Languages: English, Deutsch

What Alcor does

Alcor turns receipts into an expense sheet: attach receipt photos or PDFs (or paste receipt text) and get one row per receipt with date, merchant, gross, VAT, net, currency, and category — plus a review list, totals by category and a CSV.

  1. Reads each receipt into a structured row (date, merchant, total, VAT, currency).
  2. Suggests one of 8 categories; flags uncertain ones.
  3. Shows a review list (unreadable fields, totals that don’t add up, possible duplicates).
  4. Shows totals by category and currency and a CSV (standard or German format).

How to use it

Install from the ChatGPT Plugin Directory (link after approval), then try:

  • Turn these receipts into a spreadsheet
  • Expense report from these photos
  • Prepare these expenses for my accountant as CSV

Limitations

  • Receipt images are read by ChatGPT, not a dedicated OCR engine — please check the values against your receipts before filing.
  • Designed to leave unreadable amounts empty and flag them instead of estimating; amounts are converted only with an exchange rate you give.
  • Returns copy-paste CSV (standard or German format); a downloadable file only where ChatGPT can run code.
  • No memory across chats; receipt data is not stored.
  • Uses Midchat’s hosted tools at alcor.mcp.midchat.io (no sign-in). Does not sync to accounting software, submit claims, produce the DATEV import format, or advise on deductibility.

Troubleshooting

ProblemTry
Wrong amountCorrect it in chat and check values against the receipt before filing.
Empty fieldsIntentional when unreadable — re-photo or type the value.
Wrong categoryTell Alcor the right one, or give your own category list.
Need ExcelPaste the CSV into Excel or Google Sheets; ask for the German format for Excel DE.

Contact & reporting problems

Email support@midchat.io with: what you asked, what happened, what you expected, and a screenshot (blur real names, addresses, bank details, and receipt totals).
