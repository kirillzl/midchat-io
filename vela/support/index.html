Vela — Support

Contact: support@midchat.io · Typical response: within 3 business days · Languages: English, Deutsch

What Vela does

Vela turns PDF tables into spreadsheet data: attach a text-based PDF and get every table in source order with cleaned headers, ISO dates, plain decimals, a preview, a totals check and a CSV. Multi-page tables are stitched.

  1. Detects tables in source order.
  2. Stitches multi-page tables and removes repeated headers.
  3. Normalizes dates and amounts; shows a preview and checks totals and balances.
  4. Returns a CSV per table (standard or German format).

Scanned PDFs: without a text layer, Vela reports that OCR isn't available rather than guessing.

How to use it

Install from the ChatGPT Plugin Directory (link after approval), then try:

  • Convert this PDF to Excel
  • Extract the tables from this PDF as CSV
  • Turn this bank statement PDF into a spreadsheet

Limitations

  • Works on the PDF’s text: scanned PDFs without a text layer are reported, not OCR’d.
  • Designed to keep values as they appear in the PDF: unclear cells and ambiguous dates are flagged instead of guessed, and totals mismatches are reported, not corrected. Please compare the result with your PDF.
  • Returns copy-paste CSV (standard or German format); a downloadable file only where ChatGPT can run code.
  • No memory across chats; document content is not stored.
  • Uses Midchat’s hosted tools at vela.mcp.midchat.io (no sign-in). Does not edit/merge PDFs, convert to Word, upload files, or give tax/accounting advice.

Troubleshooting

ProblemTry
No tables foundConfirm the PDF has a text layer (scans aren’t OCR’d); try a text-based export from your bank or tool.
Wrong columnsAsk to re-detect with a bank-statement or invoice-lines preset, or name the columns.
Need ExcelPaste the CSV into Excel or Google Sheets; ask for the German format for Excel DE.
